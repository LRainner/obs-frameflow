# FrameFlow 路线图

## 目标

把 1080p30 的主机采集画面，在 OBS 里变成 **1440p60** 的实时画面，
延迟低到可以真正拿它玩游戏。

主要目标场景：

```
Xbox Series S（GTA6 1080p30）
  → HDMI → USB 采集卡（1080p60 YUY2）
  → PC（RTX 4070 + i5-13600K）
  → OBS + FrameFlow → 显示器 1440p60 / 直播
```

## 原则

1. **延迟优先** —— 端到端 80–100ms，实测而非假设。
2. **任意源** —— 采集卡、媒体、浏览器、场景、分组。
3. **零灰产依赖** —— 全部组件可分发。
4. **检测并降级** —— 每个边界情况都有兜底，绝不崩溃。
5. **状态永远可见** —— FPS、GPU 耗时、丢帧、源名称。

## 架构（已定）

| 决策 | 选择 | 理由 |
|---|---|---|
| 插件类型 | **源**（`OBS_SOURCE_TYPE_INPUT`） | 滤镜的输出尺寸被父源锁死，无法改分辨率 |
| 输入方式 | **源选择器**（源套源） | 不自己写 UVC 采集，采集交给 OBS |
| 超分 | **NVIDIA Maxine VSR** | 支持 RTX 20 系起、可分发、实测画质最好 |
| 补帧 | **NVOF + 相位插值** | 任意源帧率、任意倍率、支持 VFR |
| 图形 API | **D3D11** | Maxine / NVOF / NVENC 原生，无需跨 API 桥接 |
| 对比 | scissor 分屏 + 热键 | OBS 预览不会把鼠标事件转发给源 |

已排除：DLSS 5 NR（灰产 DLL，且 RTX 40 实测不支持）、
DLSS 4 SR（**在视频上比 bicubic 还差**，它需要引擎提供的运动矢量）。

## 里程碑

### P1 —— 管线打通（1–2 周）

**目标：** 采集画面出现在 1440p 画布上，像素不做任何处理。

- [x] CMake + 插件骨架，能在 OBS 中加载
- [x] `get_width/get_height` 由输出分辨率驱动
- [x] 源选择器属性（含循环引用检测）
- [x] 内层源 → texrender → 按输出尺寸绘制
- [x] 内层源激活（`add_active_child`），隐藏时仍出帧
- [ ] 状态行：源名称、输入/输出分辨率、FPS

**验收：** 1080p30 输入 → 1440p 输出，≤80ms，连续 10 分钟不丢帧。

### P2 —— 超分辨率（1 周）

- [x] 色彩空间管线：源空间 → texrender → 输出转换
- [x] GPU Lanczos 超分（Maxine 不可用时的降级路径）
- [ ] 接入 Maxine VSR（质量档位）
- [ ] 「验证生效」按钮（检测静默失效）
- [x] VSR 不可用时降级到 shader 缩放

**验收：** 相对 bicubic 的 PSNR 提升 ≥2dB；整体 ≤90ms。

### P3 —— 对比系统（2 天）

- [ ] 分屏对比，分割位置由属性滑条控制
- [ ] 按住热键看原图
- [ ] 分屏不进入录制/推流输出

**验收：** 预览中可见 A/B 差异，录制文件中不可见。

### P4 —— 补帧（2–3 周）

- [ ] 基于内容差分的帧检测（与帧率无关）
- [ ] 节奏分析：中位数 + EMA，支持 VFR 与 3:2 下拉
- [ ] 相位插值：`phase = (now - tA) / (tB - tA)`
- [ ] 重置协调：seek、场景切换、丢帧、分辨率变化

**验收：** 30 → 60fps，场景切换无拖影、无撕裂，附加延迟 ≤33ms。

### P5 —— 直播输出（1 周）

- [ ] NVENC 录制（H.264/HEVC）
- [ ] 虚拟摄像头，供以 OBS 为消费者的场景使用

**验收：** 同时推流 + 录制 30 分钟无音画漂移。

### P6 —— 打包与分发（1 周）

- [ ] 逐文件 manifest + SHA-256
- [ ] `THIRD_PARTY_NOTICES.md` 补齐 NVIDIA / FFmpeg / OBS 许可
- [ ] GitHub Releases，便携 ZIP
- [ ] 首次运行时下载模型（保持基础包体积小）

**验收：** 干净虚拟机上安装可用；基础包 < 30MB。

### P7 —— 监控面板（可选，1 周）

- [ ] Qt 停靠面板：前后对比预览、统计数据、快捷开关

## 技术栈

| 层 | 选择 |
|---|---|
| 语言 | C++20 |
| 构建 | CMake + vcpkg |
| 图形 | D3D11 |
| 超分 | NVIDIA Maxine VSR |
| 降噪 | Maxine Artifact Reduction |
| 光流 | NVOF |
| 编码 | NVENC |
| 封装 | FFmpeg `libavformat` |
| 虚拟摄像头 | Media Foundation |
| 界面 | OBS 属性面板（Idian 组件）+ 可选 Qt 面板 |

## 非目标（v1）

- 4070 上的实时 4K
- HDR / 10bit
- AMD / Intel 显卡
- Linux / macOS
- 8K

## 风险

| 风险 | 应对 |
|---|---|
| Maxine 运行库体积超预期 | 模型改为首次运行下载 |
| 4070 跑不满 4K | 默认 1440p，4K 给出明确警告 |
| 源循环引用 | 硬检测 + 错误状态 |
| VSR 运动画面闪烁 | 保留 bicubic 一键切换 |
| OBS API 变更 | 锁定 OBS 30+，CI 定期对最新版编译 |
